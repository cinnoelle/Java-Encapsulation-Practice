# Java Encapsulation Practice

A small Java project I made to practice object-oriented programming, specifically encapsulation and working with classes and objects.

## Features
- Creates an Animal object with a name and age
- Uses private variables with getters and setters
- Validates names and ages before updating them
- Uses a basic password check when accessing information
- Displays error messages for invalid inputs

## Concepts Used
- Java
- Encapsulation
- Constructors
- Access modifiers (private, protected, public)
- Getters and setters
- Input validation

## How to Run
1. Download `Animal.java` and `AnimalShelter.java`.
2. Open the files in Eclipse or another Java IDE.
3. Run `AnimalShelter.java` to see the program's output.
